# I build complete products, from strict database constraints to the UI pixel.

I am a full-stack engineer based in Kathmandu, working remotely with international teams. I do not just write APIs and throw them over the wall. I own features from the data model to the screen, because handoff gaps between frontend and backend are where the worst bugs hide.

I specialize in domains where correctness is non-negotiable, such as fintech, lending, and healthtech. I prefer boring, proven technology that scales.

---

### Frontend: The Screen
A backend is only as good as the interface that consumes it. I build React and Angular applications that handle complex state gracefully and actually make sense to the humans using them.

- Xmartpoint: Delivered React dashboards used daily by ops, risk, and collections teams. Handled complex financial data visualization and strict form validations using Zod and TanStack.
- Neosoftware: Built Angular frontends for ERP reporting and MIS modules, translating dense manufacturing and hospitality data into usable workflows.

### Backend: The Engine
I build modular monoliths and APIs that do not break when the business rules change. I enforce boundaries at the database level because application logic changes, but money logic should not.

- Pairable: Architected a real-time social platform from scratch in .NET. Solved high-concurrency race conditions in 1-to-1 messaging using row-level locking and kept chat usable on poor networks with SignalR and a polling fallback.
- Xmartpoint: Built a standalone reporting server to move heavy month-end aggregation off the transactional core, and delivered SSO across the ecosystem.

### The Full-Stack Advantage
When you understand both the SQL query plan and the React rendering cycle, you make better architectural decisions. I would rather spend an hour arguing about the data model today than three days debugging a state mismatch next month.
